== DESCRIPTION
Backgrounds are rectangular graphical layers composed of tiles. Tilesets
provide a collection of tiles (8x8 images), while tilemaps determine the
placement of tiles on a background.

Depending on the video mode, each background can be *regular* or
*affine*, which determines how tilemap data is interpreted and whether
affine transformations are allowed. See *display_config*(3).

=== Background configuration
The *background_config*() function configures the background with the
settings specified in the _config_ structure. The structure is defined
as follows:

[source,c]
----
struct Background {
    u16 size     : 2;
    u16 priority : 2;
    u16 overflow : 1;

    u16 tileset : 2;
    u16 tilemap : 5;

    u16 mosaic : 1;
    u16 colors : 1;
};
----

The _size_ field specifies the size of the background. Its value can be
any of the *BACKGROUND_SIZE_REG_x* or *BACKGROUND_SIZE_AFF_x* constants,
with *x* replaced by one of the following sizes:

.Background sizes
|===
|*Regular* |256x256 |512x256 |256x512 |512x512
|*Affine*  |128x128 |256x256 |512x512 |1024x1024
|===

applied to the background. See *background_mosaic*().

The _colors_ field specifies the color mode of the background,
determining how VRAM data for its tiles is interpreted. In 16-color mode
pixels are mapped to one 16-color row of the background palette, while
in 256-color mode pixels are mapped to the entire background palette.

=== Affine and Mosaic
The *background_affine*() function sets the value of the background's
affine matrix. The 2x2 matrix describes an affine transformation used
for *inverse texture mapping*. Its values are signed 16-bit fixed-point
numbers scaled by a factor of 256.
