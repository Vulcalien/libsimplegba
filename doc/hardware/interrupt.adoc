== NAME
interrupt_config, interrupt_handler, interrupt_toggle, interrupt_mask,
interrupt_wait - interrupt handling

== SYNOPSIS
[verse]
____
*#include <libsimplegba.h>*

**void interrupt_config(i32 **__id__**, i32 **__config__**);**
**void interrupt_handler(i32 **__id__**, void (+++*+++**__isr__**)(void));**

**void interrupt_toggle(i32 **__id__**, bool **__enable__**);**
**void interrupt_mask(i32 **__id__**, bool **__masked__**);**

**void interrupt_wait(i32 **__id__**);**
____

== DESCRIPTION
Interrupts are signals generated by specific events that pause the
normal flow of execution. Interrupts can be assigned an ISR (Interrupt
Service Routine), a function to execute right after the interrupt is
acknowledged. If an interrupt request is generated while an ISR is
running, the interrupt is handled after the ISR returns.

=== Interrupt configuration
The *interrupt_config*() function configures the interrupt. See the list
of interrupts below to see how _config_ is interpreted. Note that most
interrupts do not need configuration.

The *interrupt_handler*() function maps the interrupt to its _isr_. If
_isr_ is NULL, no action is performed when an interrupt request is
generated, other than acknowledging it.

=== Interrupt operation
The *interrupt_toggle*() function enables or disables the interrupt,
based on the value of _enable_. When enabled, the interrupt is unmasked.
When disabled, any pending request is discarded, and no further requests
can be generated.

The *interrupt_mask*() function masks or unmasks the interrupt, based on
the value of _masked_. Masked interrupt requests may still be generated,
but will be ignored until the interrupt is unmasked.

The *interrupt_wait*() function waits for the interrupt to occur, then
returns.

=== Interrupts
*IRQ_VBLANK*::
Periodically generated at the start of VBlank, after the last visible
row of pixels is rendered, with an approximate frequency of 59.73 Hz.

*IRQ_HBLANK*::
Periodically generated at the start of HBlank, after the last visible
pixel is rendered for each row (including hidden rows), with an
approximate frequency of 13.62 KHz.

*IRQ_VCOUNT*::
Periodically generated when a specific row of pixels begins rendering,
with an approximate frequency of 59.73 Hz. The row can be selected by
calling *interrupt_config*() with _config_ in the range [0, 227].

*IRQ_TIMER0*, *IRQ_TIMER1*, *IRQ_TIMER2*, *IRQ_TIMER3*::
Generated once a timer's counter reaches zero. See *timer_config*(3).

*IRQ_DMA0*, *IRQ_DMA1*, *IRQ_DMA2*, *IRQ_DMA3*::
Generated once a DMA transfer is complete. See *dma_config*(3).

*IRQ_KEYPAD*::
Generated when a set of buttons is pressed. The buttons can be selected
by calling *interrupt_config*(), passing a list of key constants joined
by bitwise OR. If bit 15 of _config_ is one, all buttons need to be down
at the same time; otherwise, pressing any of them will trigger the
interrupt. See EXAMPLES below.

*IRQ_GAMEPAK*::
Generated when the game cartridge is removed. Some cartridges may also
use it to signal special events.

*IRQ_SERIAL*::
Generated by the serial communication controller, triggered by events
tied to the serial protocol in use.

== NOTES
Each interrupt can only be mapped to one ISR at a time, meaning that
calling *interrupt_handler*() overwrites the previous association. If an
interrupt needs multiple ISRs, write a wrapper function:

[source,c]
----
void foo_isr(void) {
    foo_isr_a();
    foo_isr_b();
}
----

== EXAMPLES
Enable the VBlank interrupt and map an ISR to it:

[source,c]
----
interrupt_handler(IRQ_VBLANK, vblank_isr);
interrupt_toggle(IRQ_VBLANK, true);
----

Wait for a keypad interrupt until the buttons A and START are both down:

[source,c]
----
interrupt_config(IRQ_KEYPAD, KEY_A | KEY_START | BIT(15));
interrupt_toggle(IRQ_KEYPAD, true);
interrupt_wait(IRQ_KEYPAD);
----
